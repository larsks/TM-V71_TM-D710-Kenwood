## VM -- Set/Get memory VFO mode

### Set

    VM p1,p2

### Get

    VM p1

Returns: p1,p2

### Parameters

| n | function |
| - | -------- |
| 0 | Band A   |
| 1 | Band B   |

| p2 | function    |
| -- | ----------- |
| 0  | VFO mode    |
| 1  | Memory mode |
| 2  | Call mode   |
| 3  | WX mode     |
