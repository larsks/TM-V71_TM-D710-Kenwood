## MN -- Set/Read Memory name

### Set

    MN p1,p2

### Get

    MN p1

returns: p1,p2

### Parameters

| p1  | function                      |
| --- | ----------------------------- |
| nnn | Memory channel number 3 digit |

| p2       | function                   |
| -------- | -------------------------- |
| nnnnnn   | Up to 6 characters TM-V71  |
| nnnnnnnn | Up to 8 characters TM-D710 |

### Notes

- Must be uppercase for TM-V71.
