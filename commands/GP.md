## GP -- Set/Get internal GPS mode

### Set

    GP p1,p2

### Get

    GP

Returns: p1,p2

### Parameters

| p1 | function |
| -- | -------- |
| 0  | off      |
| 1  | on       |

| p2 | function          |
| -- | ----------------- |
| 0  | iGPS              |
| 1  | iGPS and data out |

### Notes

- TM-D710G only?
